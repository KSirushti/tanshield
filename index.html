Prototype — Round 1 Submission

Toxicity detection that reads Tanglish like a native speaker, not a translator.

TanShield is a multi-task classification framework that scores Tamil-English code-mixed text through two independent prediction heads — Target and Severity — instead of forcing every message into one flat offensive/not-offensive label.

The gap

Generic moderation tools weren't built for this register.

Tanglish carries cultural weight that transliteration alone erases. Existing benchmarks label content offensive or not, and by target type, but stop short of grading severity — collapsing a caste-based threat and a mildly rude joke into the same bucket.

Binary labels hide the real signal

Offensive / not-offensive tells a moderator nothing about who is targeted or how severe the harm is.

Target and severity get conflated

Treating "who it's aimed at" and "how harmful it is" as one label loses the distinction a moderator actually needs to act on.

Keyword presence isn't proof of target

A caste term in "government should end caste discrimination" isn't caste-targeted harassment — lexicons alone can't tell the difference.

No explanation, no accountability

A single label with no reasoning gives platforms and users no way to contest or understand a decision.

How we'll build it

From candidate signals to validated, multi-task predictions.

Built on the Tamil-English subset of DravidianCodeMix (the HASOC 2021 shared-task data), fine-tuning MuRIL — a transformer pretrained on transliterated Indian-language text.

Lexical trigger ≠ semantic label. A caste term appearing in a sentence doesn't mean that sentence is caste-targeted — "government should end caste discrimination" contains caste vocabulary without being an attack. Seed lexicons only produce candidate labels for both Target and Severity; every candidate is validated against human judgment before it becomes a training label.
1

Seed lexicon candidates

Target candidates come from caste/regional/appearance term lists. Severity candidates come from a separate lexicon of threat-intensity language (severe), insult/profanity terms (moderate), and teasing/sarcasm markers (mild).

→
2

Human validation

A hand-annotated subset (minimum 300–500 comments) is scored against both sets of weak labels. Agreement is reported as Cohen's κ plus per-class precision/recall — a number, not a claim.

→
3

Multi-task fine-tuning

MuRIL is fine-tuned with two independent heads on the validated labels, so the model learns contextual patterns rather than memorizing keyword presence.

→
4

Score both heads

Each input receives a distribution across Target and Severity independently, generalizing beyond the seed lexicon at inference time.

→
5

Show the reasoning

Token-level highlighting explains each head's score. A separate tone signal (sarcasm, banter) is surfaced as unconfirmed context, not a formal prediction.

Deliverables

What Round 2 ships with.

A working, judgeable system — not a slide deck.

Fine-tuned two-axis model

MuRIL fine-tuned with independent Target and Severity heads on human-validated labels, not raw keyword matches.

Interactive web demo

Text-input interface returning live scores on both axes, tested against inputs judges type themselves — not a fixed script.

Explainability output

Per-prediction token highlighting for each axis, plus a separate tone signal for sarcasm/banter shown as supporting context.

Evaluation report

Precision, recall, and F1 per class on a held-out test split for both heads, plus Cohen's κ and precision/recall of the weak labels against the hand-annotated validation subset.

Classification framework

A multi-task framework, not one flat label.

Target and Severity are predicted by two independent classification heads on the same fine-tuned model — a caste-based threat and a mildly rude joke can't collapse into the same bucket.

Target · None

No individual or group is targeted — general commentary, criticism of ideas or institutions.

Target · Individual

Directed at a specific person, whether affectionate banter or a personal attack.

Target · Group / caste / region

Directed at an identity group — caste, regional, or community-based language.

Severity · Mild

Low-harm language — teasing, sarcasm, or light criticism with no real intent to harm.

Severity · Moderate

Clearly insulting or demeaning language without an explicit threat.

Severity · Severe

Threatening, dehumanizing, or identity-based language causing serious harm.

This is a static Round 1 prototype. The annotated examples above use fixed inputs to illustrate intended output. The full system — training, scoring, and explainability — will be built and connected live during the Round 2 build window.
